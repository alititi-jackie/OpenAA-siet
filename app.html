iPhone 安装方法

  1. 用 Safari 打开本页面。
  2. 点击底部或顶部的“分享”按钮。
  3. 选择“添加到主屏幕”。
  4. 点击“添加”，桌面就会出现 OpenAA 图标。

注意：iPhone 通常不能通过网页按钮直接安装，需要手动点分享菜单。

Android 安装方法

  1. 用 Chrome 打开本页面。
  2. 点击“添加 OpenAA 到桌面”。
  3. 如果没有弹窗，点击右上角菜单。
  4. 选择“安装应用”或“添加到主屏幕”。

Android Chrome 支持时会自动弹出安装窗口。

电脑安装方法

  1. 用 Chrome 或 Edge 打开本页面。
  2. 查看地址栏右侧是否有安装图标。
  3. 点击安装，即可从桌面或开始菜单打开。
  4. 也可以收藏 ny.openaa.com 快速访问。

电脑端安装后，打开体验也会接近独立应用窗口。

OpenAA 是什么？

OpenAA 是面向纽约华人用户的生活入口网站，提供招聘信息、租房找房、二手交易、纽约 DMV 中文学习、 本地新闻、常用导航和本地服务等功能。把 OpenAA 添加到手机桌面后，可以像打开 App 一样快速进入， 适合经常查看纽约华人生活信息、发布内容或查询 DMV 学习资料的用户。
